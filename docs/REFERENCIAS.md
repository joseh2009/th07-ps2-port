# Repositórios e arquivos de referência usados

Estes projetos não estão copiados neste repositório. Cada um tem a sua própria licença; consulte o LICENSE de cada um.

| Projeto | Onde está | Papel no port |
|---|---|---|
| some100/th07 | https://github.com/some100/th07 | Base do port (decompilação do Touhou 7 1.00b). O branch `ps2-port` parte daqui. |
| GensokyoClub/th06 | https://github.com/GensokyoClub/th06 | Decompilação do Touhou 6, usada como fonte de tipos e nomes. Tem um port PS2 próprio, usado como referência. |
| makmal0962/th06-ps2 | https://github.com/makmal0962/th06-ps2 | Port do Touhou 6 para PS2 com ps2sdk, SDL2 e ps2gl. Referência de build. |
| sammwyy/th06-ps2 | https://github.com/sammwyy/th06-ps2 | Port PS2 com backend gsKit próprio. Referência de backend. |
| N0zoM1z0/th07 | https://github.com/N0zoM1z0/th07 | Fork do some100/th07. Usado como consulta. |
| TH06.ELF e th06.asm | Arquivos locais (não publicados aqui) | ELF do Touhou 6 para PS2 e a desmontagem dele. Sem autoria identificada. |

Ferramentas externas: ps2dev, PS2SDK, gsKit, audsrv (IRX embutido), PCSX2 (emulador usado nos testes), THTK (thdat e thanm), Pillow (Python, usado pelo redutor de .dat).

Dados do jogo (th07.dat, thbgm.dat) não fazem parte deste repositório e devem vir de uma cópia legítima.
